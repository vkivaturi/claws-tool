# Claws Tool

A CLI tool built with React and Ink-UI, similar to Claude Code interface.

## Description

Claws Tool is a command-line interface application built using React and Ink-UI. It provides an interactive CLI experience similar to Claude Code's interface. This is the initial version with basic hello world functionality.

## Installation

```bash
npm install
npm run build
```

## Usage

Run the CLI tool:

```bash
npm start
```

Or run directly:

```bash
node dist/cli.js
```

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build the project
npm run build

# Start the built CLI
npm start
```

## Technology Stack

- React
- Ink-UI (for CLI interfaces)
- TypeScript
- Node.js
